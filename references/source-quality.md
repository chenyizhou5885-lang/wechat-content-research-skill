# 信源质量与证据准入

本规则判断来源能否进入正式报告、支撑核心结论。链接可访问只代表技术核验通过，不代表来源质量合格。

## 1. 先建立本轮信源池

检索前按行业、议题和目标读者列出优先机构，说明其适合承担的证据角色。优先定向检索机构官网、报告库和原创栏目，再用全网搜索补充遗漏。不要先全网搜关键词，再从结果页中挑看起来相关的链接。

信源池至少覆盖任务所需的三类角色：

- 原始事实源：企业官方、监管/协会、论文、报告原文、财报、原始演讲或访谈。
- 独立解释者：行业公认的研究机构、头部垂直媒体、科技/商业媒体的原创报道。
- 企业现场：企业自己的产品、客户过程、交付记录、访谈、数据与失败经验。

名单随行业动态建立，不设跨行业永久白名单。机构知名不等于每篇内容都权威；仍需检查作者、原创性、引用和商业关系。

## 2. S/A/B/C 分级

| 等级 | 判定 | 可承担用途 |
|---|---|---|
| S | 最接近事实源头：官方公告/文档、监管与协会数据、论文、报告原文、财报、原始演讲/访谈 | 核心事实、数字、定义、事件 |
| A | 行业内公认机构或头部专业媒体的原创研究、采访与报道，作者和证据链清晰 | 趋势判断、行业解释、独立交叉验证 |
| B | 有明确编辑主体的垂直媒体、具名专家原创、专业社区深度内容 | 补充解释、案例、行业声音；不能单独支撑核心判断 |
| C | 门户自媒体号、聚合转载、无原始出处的资讯分发、软文/导购/厂商横评站、主体不明页面 | 只用于发现线索，不进入正式来源台账 |

大域名不自动获得高等级。网易号、腾讯内容号、搜狐号等按实际发布账号、作者、原创性和证据链评级；门户托管不等于门户原创。

以下情况默认 C 级，除非有充分证据推翻：

- 页面没有明确作者、发布机构或日期。
- 主要转述另一个报告、媒体或企业公告，却不链接原文。
- 同一稿件在多个门户原样分发，呈现 PR 或内容农场特征。
- 网站主营软件导购、厂商横评、招商、SEO 或商业软文。
- 域名/栏目与内容专业领域明显不匹配。
- 用搜索摘要、AI 摘要或聚合页代替正文。

## 3. 核心事实必须回溯

以下信息必须找到 S 级原始来源；找不到时标为“待核验线索”，不得写入中心判断、事实结论或标题：

- 市场规模、增长率、岗位数量、薪资、比例和预测。
- 某公司投入金额、组织调整、产品发布或战略动作。
- Gartner、IDC、麦肯锡等机构的研究结论。
- 高管原话、新概念定义、公式和首次提出时间。
- 政策、标准、监管要求、会议官方数据。

如果原始材料确实不可公开访问，可用两家相互独立的 A 级原创来源交叉验证，并明确写出“原始材料不可得”。两篇转载同一稿源不算独立验证。

## 4. 推荐选题最低证据结构

一个选题进入“强推荐”前必须同时拥有：

1. 至少 1 个 S 级原始来源。
2. 至少 1 个独立 A 级来源。
3. 至少 1 份企业一手现场材料，或明确列出必须补采的现场证据。
4. 核心判断中的每个关键事实均已回溯；不能由 B/C 级来源单独支撑。

缺少 S 或 A 时，最多标为“待验证方向”；缺少企业现场时，不得包装成企业已经形成的独家结论。不要用多个低质量来源凑数量。

## 5. 分开记录采用与淘汰

正式报告必须包含两张表：

### 正式来源台账

只收 S/A/B 级来源，记录等级、发布者、原创/转载、原始链接、用途、回溯状态与采用理由。B 级来源必须注明不能承担的核心结论。

### 待核验与淘汰线索

记录 C 级、缺日期、缺正文、无法回溯或来源冲突的页面，并写明淘汰原因及应追溯的原始机构。不得把这张表中的内容用于语言风格抽象或文章事实。

## 6. 交付前检查

- 中心判断是否至少由一个 S 和一个独立 A 支撑。
- 每个强推荐选题是否满足最低证据结构。
- 所有数字、预测、公司动作和引语是否已回到原始出处。
- 是否误把大门户上的自媒体账号当成门户原创。
- 是否仍有 C 级链接混在正式来源台账。
- 是否把机构知名度误当成具体文章质量。
- 是否解释了每个来源为什么在当前行业具有权威性。

任一项不通过时，继续回溯、降低推荐级别或删除相应结论；不要以“链接可访问”替代质量判断。
